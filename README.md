Your only mission is to complete the Live Voice MVP.

Do not expand the product.

Do not build Version 2 features.

Focus on delivering one exceptional experience:

1. User presses Listen.
2. User speaks naturally.
3. Speech is transcribed in real time.
4. Relevant Scripture appears immediately.
5. User continues ministering without interruption.
